## Questionário

### Qual é a diferença entre Working Directory, Staging Area e Repository?

Working Directory é onde ficam os arquivos que eu estou mexendo no projeto.

Staging Area é onde ficam os arquivos que eu já preparei com o git add para depois fazer o commit.

Repository é onde fica salvo o histórico dos commits do projeto.

### Qual é a diferença entre git commit e git push?

O git commit salva as alterações no histórico do Git da minha maquina.

Já o git push serve para mandar esses commits para o GitHub.

### É possível realizar vários commits antes de executar um git push?

Sim, da para fazer vários commits no computador e depois mandar todos de uma vez para o GitHub usando o git push.

### Por que é interessante realizar commits pequenos e descritivos?

Caso o programador faça alguma ca****, fica mais facil localizar o erro e corrigi-lo, tambem fica mais fácil de saber o que foi alterado em cada parte do projeto e tambem da pra voltar para alguma versão anterior.

### O que acontece com os commits locais quando ainda não executamos o git push?

Eles ficam salvos no repositório da minha maquina, mas ainda não aparecem no GitHub, ou seja no git da para trabalhar sem internet, e no gitHub não.

### Como verificar, pelo GitHub, se os commits foram enviados corretamente?

É só entrar no repositório pelo GitHub e olhar o histórico de commits e os arquivos que foram enviados.
